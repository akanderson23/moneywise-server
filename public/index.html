MoneyWise API

This server provides the course catalog for the MoneyWise website. Choose a request below to see the data it returns.

Available Requests

GET

All Courses

/api/courses

Returns every course as JSON, including its title, category, instructor, length, level, and image.
POST

Add a Course

/api/courses

Send a new course as JSON. It is checked with Joi, then added to the list and returned with its new _id and image.

  • title 3 to 60 characters
  • category Budgeting, Investing, Debt, Retirement, or Taxes
  • instructor 3 to 60 characters
  • duration like 2h 30m
  • lessons whole number from 1 to 50
  • level Beginner, Intermediate, or Advanced
  • description 10 to 200 characters

Course Images

Each course has an img_name such as images/course-budgeting.svg. Add it to the end of this server's address to load the picture.
